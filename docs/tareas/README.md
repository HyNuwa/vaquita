# Tareas

Cada integrante tiene un archivo `<slug>.md` con su plan y los archivos que le pertenecen. El plan completo por etapas está en [plan-del-equipo.md](../proyecto/plan-del-equipo.md) (sección 6).

## Quién coordina

**Maxi coordina las tareas de todos** (decisión del 24/10). Puede reasignar cualquier tarea y tomar la que haga falta para llegar a la entrega, aunque sea de otra área. Cuando toma una, la marca en el archivo del responsable ("La toma Maxi") y lo avisa en el PR. Fuera de eso, antes de tocar algo de otra área se habla con su responsable.

Lo que toque plata se sigue revisando entre dos: nadie aprueba su propio PR.
