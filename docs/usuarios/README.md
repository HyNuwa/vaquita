# Validación con usuarios

Evidencia de [D16.22](../proyecto/decisiones.md): cinco entrevistas con organizadores reales y un piloto funcional. Se registran los resultados positivos **y** los negativos.

- [guion-entrevistas.md](guion-entrevistas.md): qué preguntar.
- [resultados.md](resultados.md): resultados anonimizados.

## Reglas

- Sin nombres, teléfonos, correos, usuarios de redes ni nombres de grupos.
- Sin direcciones vinculadas a una identidad, salvo consentimiento.
- Sin detalles que permitan reconocer a alguien: se usa "E1" y una descripción general, como "comunidad dev de unas 40 personas".
- Se anota lo que pasó, no lo que hubiéramos querido oír.
